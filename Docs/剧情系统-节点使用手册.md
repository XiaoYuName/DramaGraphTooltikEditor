# 剧情系统：节点使用手册

面向**写剧情的人**。想加新节点、或想知道一条指令是怎么落到游戏里的，看隔壁那份
《剧情系统-加节点到落地全流程》。

---

## 零、五分钟上手

1. `Assets/Drama/Configs/` 里右键新建一张剧情图（`.agv`），文件名随便起。
2. 图里必须有一个**「进入」**节点，填**剧情ID** —— 这个 ID 要和游戏侧配置表
   `DramaData` 里的 ID 一致（那张表把 ID 映射到导出产物的路径）。
3. 从「进入」的输出口往后连节点，一条线串下去。
4. 结束用**终端**类的节点（「结束」/「UI结束」/「引导结束」/「跳转结束」）。
5. 导出：菜单里的 **Drama 导出窗口**，产物是 `.asset`，放进游戏工程的
   `Assets/AddressableAssets/Remote/Configs/Drama/`。
6. 调试播放：游戏工程的 **Game UITools Editor** 面板，填剧情ID → 播放剧情。

> ⚠️ **「进入」节点里的剧情ID 必须和配置表 ID 对上。** 它不参与加载（加载是查配置表的），
> 所以填错了照样能播 —— 但对话记录、已读、存档点会记错，读档恢复也会失败。
> 对不上时运行时会打一条警告，别忽略它。

## 一、连线规则（整套系统的核心）

一个输出端口可以连多条线，连几条决定了执行方式：

| 连线数 | 含义 |
|---|---|
| 0 条 | 到此结束 |
| 1 条 | **串行**：这一条完全做完（含动画、等待）才做下一条 |
| N 条 | **并行**：N 条同时开始，互不等待 |

多条支线连回同一个节点 = **汇合点**，运行时等所有支线到齐才继续，且只执行一次。

所以：

- 「立绘淡入」后面串一条 → 淡入放完才往下走
- 「立绘淡入」后面并两条（下一条指令 + 台词）→ 一边淡入一边说话
- **没有"等不等动画"的开关**，因为连线本身已经表达了这件事

## 二、节点清单

### 终端（每张图必须有「进入」，结尾用其中一个）

| 节点 | 参数 | 说明 |
|---|---|---|
| **进入** | 剧情ID | 图的起点。ID 要和配置表 `DramaData` 对上 |
| **结束** | — | 剧情到此为止 |
| **UI结束** | 界面名 | 结束并打开一个界面。界面名是游戏 UI 系统里的名字 |
| **引导结束** | 引导ID | 结束并播一段引导（引导表的 ID） |
| **跳转结束** | 目标剧情ID | 本段结束，接着播另一段剧情。连播多少段都行 |

> 「UI结束」和「引导结束」打开的东西，都是在剧情**收尾之后**才真正打开的
> （关掉剧情面板、把进剧情前的界面还回来之后）。不然引导会指到一个还没回来的按钮上。

### 对话

| 节点 | 参数 | 说明 |
|---|---|---|
| **对话** | 容器节点，里面放「台词」块 | 一次可以放多条台词，按顺序播 |
| └ **台词** | 文本 / 语音 | 文本和语音都是多语言引用。说话人、名字颜色、气泡动效在块上设 |
| **显隐** | 是否显示 | 收起 / 展开对话框。**显示是台词的副作用**，只有想藏起来时才需要这条 |
| **对话框** | 样式 | 普通框 / CG 版框。**一旦设置会一直保持**，直到下次改或本段剧情结束 |

台词自己会**等玩家点击翻页**，所以有台词的地方不需要额外的等待节点。

### 流程

| 节点 | 参数 | 说明 |
|---|---|---|
| **等待** | 时长(秒) | 到点自动往下走 |
| **等待点击** | — | **等玩家点一下**再往下走。给没有台词的场合用（比如整屏 CG） |
| **分支** | 选项数量 / 选项文字 | 玩家多选一，每个选项接一条支线 |
| **领取任务** | 任务ID | 通知任务系统 |
| **获取奖励** | 奖励表ID | 发一份奖励并弹「获得奖励」界面，**等玩家关掉再继续** |
| **打开界面** | 界面ID | 剧情中途弹一个界面，**等玩家关掉再继续** |

> 「获取奖励」和「打开界面」在**自动 / 跳过**模式下不等人：界面亮一下自己收掉，剧情接着走。
>
> 「打开界面」和「UI结束」的区别是时机：那个是"剧情结束了顺便开个界面"、开完剧情就没了；
> 这个是演到一半插一个界面，玩家关掉之后剧情接着演。
>
> ⚠️ **奖励只发一次**：读档恢复时这两条指令都会跳过（重放不该重复发奖励、也不该弹界面）。

> 「等待」是**到点自动走**，「等待点击」是**等人**。
> 想要"等点击但最多 N 秒"，把两个连成并行分支即可。
> 跳过模式和读档恢复期间，这两个都不等人。

### 立绘

| 节点 | 说明 |
|---|---|
| **立绘骨骼 / 立绘图 / 立绘Live2D** | 三种资源类型，参数完全一样：显示方式（直接显示/隐藏/淡入/淡出）、方向、位置、缩放、时长、缓动 |
| **立绘变换** | 容器，里面放「位置」「旋转」「缩放」块 |
| **角色动作** | 相对当前位置做偏移小动作，可循环 |
| **角色抖动** | 容器，里面放「抖动」（硬抖）或「震动」（柔震）块 |
| **皮肤** | 换 Spine 皮肤 |
| **骨骼动画 / 序列动画** | 播 Spine 动画（轨道、循环、倍速） |
| **触发 Bool / Int / Float / Trigger** | 设置立绘 Animator 的参数，Live2D 的表情动作走这个 |
| **讲话人缩放** | 「非说话人压暗 / 微缩」的**总开关**。不针对任何角色，一般开头设一次 |

> 「讲话人缩放」只是开关，真正的效果发生在每条台词上：说话人恢复原样、其他人压暗微缩。

### CG

CG = 全屏的一张大图（本工程是全屏 Live2D）。**单槽位**，同时只有一张，所以这一族节点都没有 ID。

| 节点 | 说明 |
|---|---|
| **CG出现 / CG关闭** | 时长为 0 就是瞬时。**进 CG 时立绘整层自动藏起来，退出时恢复** |
| **CG变换 / CG动作 / CG抖动** | 和立绘那套参数结构完全一样 |
| **CG触发 Bool / Int / Float / Trigger** | CG 模型的 Animator 参数 |

> CG 盖住全屏、对话框又藏着的时候，记得用「等待点击」把节奏交回玩家，
> 否则画面会自己往下走。

### 场景 / 演出

| 节点 | 参数 | 说明 |
|---|---|---|
| **切换背景** | 背景ID / 转场样式 / 淡入淡出时长 | 剧情舞台的背景图 |
| **背景变化** | 容器，放「位置」「旋转」「缩放」块 | 做镜头感 |
| **场景**（转场） | 容器，放「淡入淡出」「竖条」「百叶窗」块 | 全屏转场 |
| **游戏场景** | 大场景ID / 小场景ID | 切**游戏里真实的场景**，不是背景图 |
| **场景显隐** | 显示场景NPC / 显示场景默认UI | 见下 |
| **播放音乐** | 音频ID | BGM，走游戏的音频配置表 |

> **「切换背景」的转场**（淡入淡出 / 竖条 / 百叶窗）：新背景从旧背景上长出来，
> 中间不会露出底色。条纹的样子和「场景」转场是同一套，所以两处混用不会看出割裂。
> **两个时长只有长的那个生效** —— 这一族转场只有一条进度线（没有先出后进之分），
> 填一个就够了。跳过模式下自动变瞬切。本剧本第一次换背景也是瞬切（没有旧图可过渡）。

> **进剧情时，场景 NPC 和地图配置的默认UI 会自动收起来**（剧情要独占屏幕），
> 剧情结束原样还回去。所以只有**想让它们露出来**的时候才需要「场景显隐」。
>
> 它改的是一个**持续状态，切场景也保持**。要让新场景露出 NPC，
> 把「场景显隐」摆在「游戏场景」**前面** —— 摆后面的话 NPC 会先冒出来一帧再被收掉。
>
> 大场景切换的限制：在小场景里只能换小场景。要跨大场景，
> 先用一条「游戏场景」回大地图（小场景填 -1），再进目标场景。

### 容器节点 ↔ 能往里放的块

有些节点是**容器**，本身不干活，靠往里放"块"来表达。哪个块能进哪个容器是写死的，
拖不进去就是不允许：

| 容器 | 能放的块 |
|---|---|
| **对话** | 台词 |
| **立绘变换** / **背景变化** / **CG变换** | 位置、旋转、缩放 |
| **角色抖动** / **CG抖动** | 抖动（硬抖）、震动（柔震） |
| **角色动作** / **CG动作** | 小动作 |
| **场景**（转场） | 淡入淡出、竖条、百叶窗 |

同一个块放进不同容器，作用对象就不同 —— **是容器决定语义，不是块**。
比如「位置」块放进「立绘变换」是移立绘，放进「背景变化」是移背景。

## 三、常见套路

**一段普通对话**

```
进入 → 切换背景 → 播放音乐 → 立绘骨骼(淡入) → 对话[台词×N] → 结束
```

**整屏 CG，看够了再走**

```
… → CG出现 → 显隐(隐藏对话框) → 等待点击 → CG关闭 → 显隐(显示) → 对话[…]
```

**一边淡入一边说话**（并行）

```
              ┌→ 立绘骨骼(淡入 2s)
立绘变换 ──────┤
              └→ 对话[台词]
```

**选项分支**

```
对话[台词] → 分支 ┬→ 支线A … ┐
                  └→ 支线B … ┴→ 汇合节点 → 继续
```

**剧情结束后接引导**

```
… → 对话[台词] → 引导结束(引导ID=1001)
```

## 四、播放模式与玩家操作

| 操作 | 效果 |
|---|---|
| 点击屏幕 / **空格** | 推进。打字机还在跑就先显示全文，跑完了才翻页 |
| AUTO | 自动翻页，语音没念完不计时 |
| SKIP | 快进。**默认只跳已读**，撞到没看过的台词会自动停下 |
| LOG | 对话记录，可以回看、点小喇叭重播语音 |

- 跳过模式下点一下屏幕 = **刹车**（退回正常模式），这一下不翻页
- 玩家选完选项会自动关掉跳过；开 LOG 也会
- 「跳过全部 / 只跳已读」是设置项，已读记录是**跨存档**的

## 五、写剧情时容易踩的

| 现象 | 原因 |
|---|---|
| 导出后某个节点没生成指令 | 那个节点还没接导出翻译，看导出窗口的警告列表 |
| 剧情播到一半停住 | 某条指令在等一个永远不来的东西；检查是不是把「等待点击」放在了自动流程里 |
| 立绘/CG 动画被"吞"了 | 连成了并行分支。并行的语义就是不等它 |
| 对话记录空白 / 读档回不去 | 「进入」节点的剧情ID 和配置表对不上 |
| 切场景后 NPC 冒出来了 | 「场景显隐」摆在了「游戏场景」后面，要摆前面 |
| 改了剧情图，老存档的对话记录少了几条 | 那几句的文本键改过或被删了，属于预期 |
